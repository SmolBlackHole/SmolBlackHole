# Hi, I'm SmolBlackHole 👋

CS Master's student from Germany. I build things across embedded systems, full-stack development, infrastructure, and occasionally whatever weird optimization problem manages to keep me awake long enough.

Most of my projects start with "this shouldn't take too long".

They usually do.

> Building systems nobody asked for and benchmarking them anyway.

<br/>


## ⚙️ What I actually do

I like building complete systems rather than isolated demos.

That can mean squeezing a chess engine onto an ESP32, designing a backend and frontend around an actual workflow, building search and optimization algorithms, or spending far too much time making infrastructure behave properly.

Most of my work ends up somewhere between:

`embedded ↔ backend ↔ frontend ↔ infrastructure ↔ questionable research rabbit hole`

I care a lot about architecture, reproducibility, performance, and software that still makes sense six months after I wrote it.

## 🔧 Things I'm working on

Most of my serious projects are private. I tend to keep source code to myself unless there's a good reason to publish it.

| Project | What it is |
|---|---|
| **Chessy** | Tiny ESP32-S3 chess computer with a custom C++ engine. The current ESP build benchmarks at roughly **2100 Elo** in a UCI-calibrated Stockfish ladder. |
| **Hadamard-668** | Computational search around the unresolved Hadamard matrix of order 668. The current GS4 solver evaluates **20M candidates per seed at n=52 in ~300 ms on average**. |
| **Trady** | Trading and backtesting system focused on reproducible market data, execution, strategy evaluation and risk. |
| **Montefolio** | Financial planning and portfolio simulation project. Currently mostly dormant. |
| **[Mermaid ELK Renderer](https://github.com/SmolBlackHole/mermaid-elk-renderer)** | Obsidian plugin for Mermaid diagrams using ELK layouts. **700+ downloads.** [Install via Obsidian Community Plugins](https://community.obsidian.md/plugins/mermaid-elk-renderer). I use Obsidian pretty heavily myself. My university vault alone is currently around 190 files and 150k words, with diagrams in most notes. My private vault is roughly the same size. |
